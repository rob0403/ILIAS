# Use of AI assisted Code in ILIAS

## Foreword:
Large Language Models and Agentic Harnesses have found their way into everyday life and it is unlikely that they will disappear anytime soon. Thus, we should integrate them with the best of our abilities into the ILIAS development process and at the same time make sure that quality improves rather than deteriorates when using AI. To achieve this we want to create this as a living document that steadily adapts to the fast changes that AI brings.

## Using AI in software development:
In general AI generated code is allowed to be used for ILIAS software development. There are, however, some requirements for this:
- All AI-generated code must be reviewed by a code authority before merging it.
- All contributions via Pull Requests should be at least reviewed or tested before they are created.
- AI-generated code should be attributed in Pull Requests (see chapter [Attribution](#Attribution)).

## Attribution:
- When you use code that was written by an AI in significant parts we ask you to describe in the PR how this code was created. This helps everyone in tracking the role of AI in ILIAS software development and also in sharing best practices between ILIAS Code Authorities. 
- The proposed format for attribution is: 
    - Assisted by: [AI_COMPANY]:[MODE_NAME], [TOOL_USED]
    - e.g. "Assisted by: Anthropic:Claude-Opus-4.8, Claude Code"
    
## Role of the TB:
The Technical Board will accompany the process of AI-generated contributions to the best of its abilities by scouting for best practices and bringing all ILIAS authorities together to together quality assure the ILIAS source code. The TB is always happy to receive feedback or recommendations on how to use AI in ILIAS software development.
